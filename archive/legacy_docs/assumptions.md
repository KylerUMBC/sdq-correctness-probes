# Assumptions

1. Surface-form transformations induce structured (not arbitrary) changes in hidden-state trajectories.
2. These changes are **local** and **state-dependent** — no single global linear transform explains them.
3. Semantically equivalent prompts share the same latent reasoning dynamics up to time reparameterization and local gauge.
4. The observed hidden state is generated by $h_t = D_{u_t}(z_t) + \epsilon_t$.
5. Local transport operators $G_t$ are smooth, near-identity, and low-rank.
6. Centroid subtraction is a crude first-order approximation to real SDQ, not the object itself.
7. Answer identity is **not** sufficient for semantic equivalence — reasoning path matters.
